# 🛸 SNI PINGER

**Advanced Network Diagnostic Tool for Android**

SNI Pinger — это мощное приложение для Android, предназначенное для глубокой сетевой диагностики, проверки SNI (Server Name Indication), TLS-сертификатов и доступности хостов. Идеально подходит для сетевых инженеров, системных администраторов и любых пользователей, которым необходимо проверить доступность доменов через конкретный IP-адрес.

---

## ✨ Ключевые возможности

### 🔍 3 Режима работы
1. **Свой SNI (Single)**: Проверка одного конкретного SNI-хоста (домена) через указанный IP.
2. **Whitelist**: Автоматическая загрузка актуального списка SNI из репозитория и пакетная проверка всех доменов.
3. **Massive**: Ручной ввод списка SNI (каждый с новой строки) для массового тестирования с подробным отчетом.

### ⚡ Мгновенная и Параллельная Диагностика
Использует современные **Kotlin Coroutines** для максимально быстрого выполнения проверок:
- **TCP Reachability:** Проверка портов 443 (HTTPS) и 80 (HTTP).
- **TLS Handshake:** Проверка успешности рукопожатия, версии протокола и используемого шифра.
- **HTTP Status:** Получение кодов ответа, заголовков сервера и локаций перенаправления.
- **DNS Analysis:** Скорость разрешения имен и проверка соответствия IP.
- **RTT (Ping):** Точное измерение времени отклика (Latency).

### 🔒 Анализ TLS и Сертификатов
- Поддержка **TLS 1.2** и **TLS 1.3**.
- Проверка **HTTP/2 (H2)**.
- **SNI Match:** Верификация соответствия запрошенного SNI и данных в сертификате сервера.

### 🌍 Геолокация и IP Инфо
- Интеграция для получения Geo-данных IP: Страна, Город, Провайдер (Org) и источник данных.

### 🎛️ Продвинутый UI и Контроль
- **Material 3 Design:** Современный интерфейс с поддержкой динамических тем.
- **Тёмная/Светлая тема:** Быстрое переключение прямо из приложения.
- **Многоязычность:** Встроенный переводчик на базе **ML Kit**, позволяющий переводить интерфейс на лету.
- **Пауза / Резюме / Отмена:** Полный контроль над длительными проверками.
- **Умный фильтр:** Возможность скрыть медленные хосты (порог пинга).
- **Терминал:** Интерактивное логгирование процесса в реальном времени.

---

## 🚀 Как пользоваться

1. **Введите целевой IP:** Адрес сервера, который вы хотите протестировать.
2. **Выберите режим:** Переключайтесь между одиночной проверкой или массовыми списками.
3. **Запустите проверку:** Нажмите кнопку "Check" и наблюдайте за процессом в терминале или через карточки результатов.
4. **Экспорт:** Скопируйте результаты в буфер обмена одной кнопкой для последующего анализа.

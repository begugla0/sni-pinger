# 🛸 SNI PINGER

**Advanced Network Diagnostic Tool for Android**

SNI Pinger — это мощное приложение для Android, предназначенное для глубокой сетевой диагностики, проверки SNI (Server Name Indication), TLS-сертификатов и доступности хостов. Идеально подходит для сетевых инженеров, системных администраторов и любых пользователей, которым необходимо проверить доступность доменов через конкретный IP-адрес.

---

## ✨ Ключевые возможности

### 🔍 3 Режима работы
1. **Свой SNI**: Проверка одного конкретного SNI-хоста (домена) через указанный IP.
2. **Whitelist**: Автоматическая загрузка списка SNI по URL и пакетная проверка всех доменов.
3. **Massive**: Ручной ввод списка SNI (каждый с новой строки) для массового тестирования с подробным отчетом.

### ⚡ Мгновенная и Параллельная Диагностика
Использует современные **Kotlin Coroutines** для параллельного выполнения проверок:
- **TCP-порты:** 443, 80, 53, 8080 (проверка на открытость).
- **TLS Handshake:** Проверка соединения, времени отклика и поддержка версий.
- **HTTP-статус:** GET и HEAD запросы с получением кодов ответа.
- **DNS-разрешение:** Скорость и корректность IP.

### 🔒 Глубокий Анализ Безопасности (TLS)
- Поддержка **TLS 1.2** и **TLS 1.3**.
- Проверка **HTTP/2 (ALPN)**.
- Детали сертификата: Кто выдал, срок действия, SAN-записи.
- **SNI Match:** Проверка, совпадает ли запрошенный домен с сертификатом.

### 🌍 Геолокация и Информация о владельце
- Интеграция с **ipinfo.io** для получения Geo-данных IP (Страна, Город, Провайдер, ASN).
- Определение владельца домена.

### 🎛️ Полный контроль над проверкой
- **Пауза / Продолжить / Отмена** в процессе массовой проверки.
- **Фильтр:** Показать только SNI с низким пингом (<100ms).
- **Сохранение настроек:** Последний IP, список SNI и режим восстанавливаются при перезапуске.

## 📱 Интерфейс приложения

Приложение полностью переработано для **Тёмной темы** и удобства чтения больших объемов данных.

### Карточки результатов
Результаты разбиты на 5 логических секций:
1. **🌍 Geo / Ownership:** Данные об организации, городе, стране и владельце домена.
2. **🔌 TCP / Network:** Статус портов и время подключения.
3. **🔒 TLS / Certificates:** Версии шифрования, детали валидности сертификата.
4. **🌐 HTTP:** Статус коды, заголовки сервера, редиректы.
5. **🎯 IP / DNS:** Разрешение доменных имен и статус IP.

### 📟 Терминал
Внизу экрана (режимы Whitelist/Massive) доступен терминал, пишущий статус проверки в реальном времени:
`[HH:mm:ss] [STATUS] 45ms example.com`
Терминал можно свернуть или развернуть нажатием на стрелку.

## 🚀 Быстрый старт

1. **Запустите приложение.**
2. **Введите IP:** Адрес прокси-сервера или VPS (по умолчанию `1.1.1.1`).
3. **Выберите режим:**
   - Для одного домена введите его в поле "SNI Host" и нажмите "Проверить".
   - Для списка нажмите на вкладку "Whitelist" (автоматическая загрузка) или "Massive" (вставьте свой список).
4. **Наслаждайтесь результатами** или скопируйте их в буфер обмена кнопкой "Copy".
